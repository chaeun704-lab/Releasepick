# 재정경제부 정책카드뉴스 본문 디자인 템플릿
## 모모&페페 시리즈 — 본문 1~3페이지

> **표지 템플릿(`multipage_momopepe_front.txt`)과 연계 사용**
> 본문은 표지에서 확립된 배경 테마·포인트 컬러·폰트 체계를 그대로 이어받는다.

---

## 0. 표지·본문 공통 디자인 시스템 (가장 중요 — 톤앤매너 통일)

표지(`multipage_momopepe_front.txt`)와 본문(`multipage_momopepe_body.txt`)은 **하나의 시리즈**다.
아래 항목은 표지·본문에서 100% 동일하게 적용하여 톤앤매너를 일치시킨다. (이 §0이 이후 모든 섹션보다 우선한다.)

| 항목 | 공통 규칙 (표지·본문 동일) |
|---|---|
| 비율/크기 | 1000 × 1350px (세로 20:27) |
| 기본 배경 테마 | **라이트 `#F8F8F8`(흰 배경, 기본)**. 다크 `#1C1C1C` / 블루 공식 `#1A3A6B`는 선택, **시리즈 내 표지·본문 전 페이지 동일 테마** |
| 카드/박스 배경 | 다크: `#2A2A2A` · 흰 카드 `#F0F0F0` / 라이트: `#FFFFFF` · `#F0F0F0` |
| 주 포인트 컬러(타이틀·수치·강조) | **라임 그린 `#7FD62C`** |
| 보조 포인트 컬러(배지·원형 강조) | **노란색 `#FFD700`** |
| 블루 포인트(테두리·블루 테마) | `#1A3A8F` |
| 타이틀 컬러 | **라이트 배경: 차콜 `#1A1A1A` + 라임 그린 `#7FD62C` 강조** / 다크 배경: 라임 그린 `#7FD62C`. (강조 단어 노란색 `#FFD700` 허용) |
| 본문/설명 텍스트 | 라이트 배경 `#2A2A2A` / 다크 배경 `#E8E8E8` |
| 폰트 — 타이틀 | 배달의민족 도현체 / 여기어때 잘난체 / Noto Sans KR Black |
| 폰트 — 본문/서브 | Noto Sans KR (본고딕) SemiBold~Regular |
| 폰트 — 말풍선 | 배달의민족 주아체(손글씨풍) |
| 캐릭터 | 3D 고양이 **모모(주황/베이지 자켓)·페페(회색/흰 셔츠+파란 넥타이)**, 의상 고정 |
| 공통 장식 오브젝트 | **종이비행기 `#4A90D9`(우상단, -30°)**, 흰 반투명 점선 아크, 별·스파클(다크 배경), 돋보기 — 표지·본문 동일하게 반복 |
| 재정경제부 MI | 하단 중앙, 너비 22~28%, 다크=흰 로고 / 라이트=컬러 로고 |
| 내부 테두리 | 선택 사항. 사용 시 표지·본문 모두 포인트 블루 `#1A3A8F` 4~6px 동일 적용 |

> 핵심: **타이틀은 라임 그린, 보조 강조는 노란색, 배경 테마는 시리즈 전체 동일**.
> 표지만 노란 타이틀/실사 배경을 쓰고 본문은 초록 타이틀/다크 배경을 쓰는 식의 불일치를 금지한다.

## 1. 표지→본문 연속성 원칙

| 항목 | 표지 | 본문 공통 |
|------|------|-----------|
| 배경 테마 | 다크 `#1C1C1C` (기본) / 라이트 `#F8F8F8` / 블루 `#1A3A6B` | **표지와 동일 테마·hex 유지** |
| 타이틀 컬러 | 라임 그린 `#7FD62C` (강조 노랑 `#FFD700`) | **동일 — 라임 그린 기본** |
| 포인트 컬러 | 라임 그린 `#7FD62C` + 노란 `#FFD700` | **동일 컬러 유지** |
| 공통 장식 | 종이비행기·스파클·점선 아크 | **동일 오브젝트 반복** |
| 캐릭터 | 크게(포스터 50~60%) 중앙 | **작게(20~35%) 하단·측면 배치** |
| 재정경제부 MI | 하단 중앙 | **본문 전 페이지 하단 중앙 동일 배치** |
| 시리즈 로고 | 상단 중앙 (큰 버전) | **상단 우측 (소형 버전, 30~36px)** |

## 4. 컬러 시스템 (본문 확장)

### 4-1. 배경 — 표지 테마 그대로 유지 (§0 공통: 라이트가 기본)

| 테마 | 본문 배경 | 카드/박스 배경 |
|------|-----------|---------------|
| **라이트 (기본)** | `#F8F8F8` (흰 배경) | `#FFFFFF` (흰 카드) / `#F0F0F0` (회색 카드) |
| **다크 (선택)** | `#1C1C1C` | `#2A2A2A` (연한 다크) / `#F0F0F0` (흰 카드) |

> 표지가 라이트(흰 배경)면 본문도 라이트, 표지가 다크면 본문도 다크. **표지·본문 배경은 반드시 동일 테마.**

### 4-2. 본문 전용 컬러 팔레트

| 역할 | 색상명 | 헥스 코드 |
|------|--------|-----------|
| 페이지 타이틀 | 라임 그린 | `#7FD62C` |
| 카드 제목 (강조) | 라임 그린 | `#7FD62C` |
| 카드 제목 (기본) | 흰색 | `#FFFFFF` |
| 본문 텍스트 (다크 배경) | 밝은 회색 | `#E8E8E8` |
| 본문 텍스트 (라이트 배경) | 진한 회색 | `#2A2A2A` |
| 카드 레이블 배경 | 라임 그린 | `#7FD62C` |
| 카드 레이블 텍스트 | 검정 | `#1A1A1A` |
| 구분선 (점선) | 중간 회색 | `#555555` |
| 주의사항 배너 배경 | 연한 크림 | `#F5EDD0` |
| 주의사항 배너 핀 | 빨간색 | `#E03030` |
| 수치 강조 | 라임 그린 | `#7FD62C` |
| CTA 버튼 배경 | 라임 그린 | `#7FD62C` |
| CTA 버튼 텍스트 | 검정 Bold | `#1A1A1A` |
| 장식 오브젝트 | 종이비행기 파란색 | `#4A90D9` |

### 4-3. 카드 보더 처리

- **흰 카드 (다크 배경 위)**: `border: 2px solid #3A3A3A` + `border-radius: 16px`
- **초록 강조 카드**: `border: 2px solid #7FD62C` + `border-radius: 16px`
- **회색 카드 (비교용)**: `background: #3A3A3A` + `border-radius: 16px`

## 5. 타이포그래피 (본문)

### 5-1. 폰트 역할별 스펙

| 역할 | 폰트 | 두께 | 크기 (1000px 기준) | 색상 |
|------|------|------|-------------------|------|
| **페이지 타이틀** | 배달의민족 도현체 / 여기어때 잘난체 | Black | 72~90px | 라이트 배경: 차콜 `#1A1A1A`(강조 라임 `#7FD62C`) / 다크 배경: 라임 `#7FD62C` |
| **카드 헤드라인** | Noto Sans KR / 본고딕 | ExtraBold | 40~52px | 라임 그린 or 흰색 |
| **카드 소제목 (레이블)** | Noto Sans KR | Bold | 28~34px | 검정 (#1A1A1A) |
| **본문 텍스트** | Noto Sans KR | Regular~Medium | 26~32px | `#E8E8E8` or `#2A2A2A` |
| **강조 수치** | Noto Sans KR / 본고딕 | Black | 52~72px | 라임 그린 `#7FD62C` |
| **CTA 버튼 텍스트** | Noto Sans KR | Bold | 24~28px | 검정 |
| **말풍선 텍스트** | 배달의민족 주아체 | Regular | 28~36px | 검정 or 흰색 |
| **주의사항 텍스트** | Noto Sans KR | Regular | 24~28px | `#2A2A2A` |
| **시리즈 로고 (소형)** | Noto Sans KR | Bold | 22~28px | 흰색 |

### 5-2. 타이틀 텍스트 스타일

- 페이지 타이틀: 자간 **-60 ~ -80**, 좌측 정렬 (중앙 정렬도 허용)
- 타이틀 끝에 **느낌표(!)** 또는 **물음표(?)** 포함 권장
- 타이틀 외곽선(Stroke): 없음 또는 검정 1~2px (라임 그린 텍스트는 외곽선 불필요)
- **줄 간격**: 타이틀 1.0~1.1 / 본문 텍스트 1.4~1.6

## 6. 콘텐츠 블록 레이아웃 유형 (3종)

### ─ 유형 A: 좌우 2단 비교 카드

> 사용 예: 전용계좌 vs 일반계좌, 혜택 있음 vs 없음, 전/후 비교

```
┌────────────────────────────────────────┐
│  [초록 레이블]        [회색 레이블]     │
│                                        │
│  ┌──────────────┐  ┌──────────────┐   │
│  │ 카드 제목    │  │ 카드 제목    │   │
│  │ (라임 그린)  │  │ (흰색)       │   │
│  │─────────────│  │─────────────│   │
│  │ 소제목      │  │ 소제목      │   │
│  │ 내용 텍스트  │  │ 내용 텍스트  │   │
│  │             │  │             │   │
│  │ 소제목      │  │ 설명 텍스트  │   │
│  │ 내용 텍스트  │  │             │   │
│  └──────────────┘  └──────────────┘   │
└────────────────────────────────────────┘
```

**세부 규칙:**
- 카드 너비: 각 **460px** (간격 60px)
- 카드 배경: 왼쪽 `#F0F0F0` (흰/연회색), 오른쪽 `#3A3A3A` (다크 회색)
- 레이블: 카드 상단에 라임 그린/회색 **둥근 태그** (radius 20px, 패딩 12px 24px)
- 카드 내부 구분: 점선 (`border-top: 1.5px dashed #888`)
- 카드 하단: **CTA 버튼** 선택적 배치

### ─ 유형 B: 좌측 레이블 + 우측 내용 테이블

> 사용 예: 항목별 정보 나열 (판매기간, 가입대상, 가입방법 등)

```
┌────────────────────────────────────────┐

│  │ [레이블] │ 메인 텍스트           │  │
│  └──────────┴───────────────────────┘  │
│  ┌──────────┬───────────────────────┐  │
│  │ [레이블] │ 메인 텍스트           │  │
│  │          │ · 세부항목1           │  │

```

**세부 규칙:**
- 행 배경: `#2E2E2E` (다크) 또는 `#EFEFEF` (라이트), 행마다 동일 배경
- 행 높이: 내용에 따라 가변 (최소 100px)
- 레이블 셀: 너비 **200px**, 배경 `#3A3A3A` (다크) / `#E0E0E0` (라이트), 텍스트 Bold 28~32px
- 내용 셀: 나머지 너비, 메인 텍스트 26~30px + 서브 텍스트 라임 그린 22~24px
- 행 간 구분선: `1px solid #444`
- 전체 테이블 `border-radius: 16px`, overflow hidden

## 7. 보조 UI 컴포넌트

### 7-1. 수치 비교 배너 (횡형 테이블)

```
┌─────────────────────────────────────────┐
```

- 항목명: 22~26px, `#E8E8E8`

```
│  ·────────────점선──────────────·    │
│  ·내용 텍스트 1                       │
│  ·내용 텍스트 2 (강조어 라임 그린)     │
│  ·내용 텍스트 3                       │
└───────────────────────────────────────┘
```

- 배경: `#F5EDD0` (크림/베이지)
- 모서리 상단 좌우: 빨간 핀(압정) 장식 (`#E03030`, 지름 22px)
- 제목: Bold 36~42px, 검정 `#1A1A1A`
- 내용: Regular 24~28px, 검정, 중앙 정렬
- 강조 단어: 라임 그린 `#7FD62C`, Bold

### 7-3. 말풍선 (캐릭터 대사)

- 스타일 A: **흰 사각형 버블** (radius 16px) + 꼬리 → 캐릭터 대사
- 스타일 B: **노란색 원형 배지** (`#FFD700`) → 단어/퍼센트 강조
- 텍스트: 손글씨풍 폰트, 26~34px
- 위치: 캐릭터 좌측 상단 or 우측 상단

### 7-4. 장식 오브젝트

- **종이비행기**: 상단 우측 코너, 파란색 `#4A90D9`, 기울기 약 -30°
- **점선 곡선**: 배경에 흰색 반투명(`rgba(255,255,255,0.15)`) 점선 아크
- **별·스파클**: 다크 배경에 흰/노란 소형 별 2~5개 (타이틀 주변)
- **돋보기**: 우측 하단 장식용, 흰색 반투명, 직경 100~140px
- **클립/핀**: 카드 상단 코너에 금속 질감 클립 이미지

## 8. 본문 캐릭터 배치 가이드

| 페이지 유형 | 캐릭터 | 크기 | 위치 | 포즈/소품 |

## 13. 페이지 간 시각적 연결성 유지 규칙

1. **배경 테마 고정**: 시리즈 내 모든 페이지(표지+본문) 동일 배경색
2. **타이틀 컬러 일관성**: 표지=노란색 or 초록색, 본문=**초록색 통일**
3. **장식 오브젝트 반복**: 종이비행기를 전 페이지 상단에 배치 (위치·크기 동일)
4. **캐릭터 동일성**: 동일 캐릭터(모모/페페) 시리즈 내 고정 사용, 의상 변경 금지
5. **MI 위치 고정**: 전 페이지 하단 중앙, 동일 크기
6. **카드 radius 통일**: 전 페이지 카드/박스 border-radius 동일값 (16px 권장)
7. **점선 스타일 통일**: 카드 내 구분선을 점선(dashed)으로 통일
8. **CTA 버튼 컬러 고정**: 라임 그린 배경 + 검정 Bold 텍스트
