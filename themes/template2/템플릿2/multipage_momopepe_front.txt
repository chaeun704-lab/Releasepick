## 0. 표지·본문 공통 디자인 시스템 (가장 중요 — 톤앤매너 통일)

표지(`multipage_momopepe_front.txt`)와 본문(`multipage_momopepe_body.txt`)은 **하나의 시리즈**다.
아래 항목은 표지·본문에서 100% 동일하게 적용하여 톤앤매너를 일치시킨다. (이 §0이 이후 모든 섹션보다 우선한다.)

| 항목 | 공통 규칙 (표지·본문 동일) |
|---|---|
| 비율/크기 | 1000 × 1350px (세로 20:27) |
| 기본 배경 테마 | **라이트 `#F8F8F8`(흰 배경, 기본)**. 다크 `#1C1C1C` / 블루 공식 `#1A3A6B`는 선택, **시리즈 내 표지·본문 전 페이지 동일 테마** |
| 카드/박스 배경 | 다크: `#2A2A2A` · 흰 카드 `#F0F0F0` / 라이트: `#FFFFFF` · `#F0F0F0` |
| 주 포인트 컬러(타이틀·수치·강조) | **라임 그린 `#7FD62C`** |
| 보조 포인트 컬러(배지·원형 강조) | **노란색 `#FFD700`** |
| 블루 포인트(테두리·블루 테마) | `#1A3A8F` |
| 타이틀 컬러 | **라이트 배경: 차콜 `#1A1A1A` + 라임 그린 `#7FD62C` 강조** / 다크 배경: 라임 그린 `#7FD62C`. (강조 단어 노란색 `#FFD700` 허용) |
| 본문/설명 텍스트 | 라이트 배경 `#2A2A2A` / 다크 배경 `#E8E8E8` |
| 폰트 — 타이틀 | 배달의민족 도현체 / 여기어때 잘난체 / Noto Sans KR Black |
| 폰트 — 본문/서브 | Noto Sans KR (본고딕) SemiBold~Regular |
| 폰트 — 말풍선 | 배달의민족 주아체(손글씨풍) |
| 캐릭터 | 3D 고양이 **모모(주황/베이지 자켓)·페페(회색/흰 셔츠+파란 넥타이)**, 의상 고정 |
| 공통 장식 오브젝트 | **종이비행기 `#4A90D9`(우상단, -30°)**, 흰 반투명 점선 아크, 별·스파클(다크 배경), 돋보기 — 표지·본문 동일하게 반복 |
| 재정경제부 MI | 하단 중앙, 너비 22~28%, 다크=흰 로고 / 라이트=컬러 로고 |
| 내부 테두리 | 선택 사항. 사용 시 표지·본문 모두 포인트 블루 `#1A3A8F` 4~6px 동일 적용 |

> 핵심: **타이틀은 라임 그린, 보조 강조는 노란색, 배경 테마는 시리즈 전체 동일**.
> 표지만 노란 타이틀/실사 배경을 쓰고 본문은 초록 타이틀/다크 배경을 쓰는 식의 불일치를 금지한다.

## 2. 레이아웃 구조 (표지 기준)

```
┌─────────────────────────────┐  ← 외곽 테두리 (4~6px, 포인트 컬러)
│                             │
│  [시리즈 로고 / 에피소드 번호]  │  ← 상단 중앙, 상단에서 4~5% 위치
│                             │
│  [메인 타이틀 텍스트 1줄~2줄]  │  ← 전체 높이의 10~22% 구간
│  [서브타이틀 / 한줄 설명]      │  ← 타이틀 바로 아래, 배너형 박스
│                             │
│                             │
│     [메인 캐릭터 이미지]       │  ← 전체 높이의 25~85% 구간 (중앙 차지)
│     (3D 고양이 모모/페페)      │
│                             │
│  [말풍선 A]   [말풍선 B]      │  ← 캐릭터 좌/우에 배치
│                             │
│       [재정경제부 MI]         │  ← 하단 중앙, 하단에서 3~5% 위치
└─────────────────────────────┘
```

## 3. 컬러 시스템

### 3-1. 배경 컬러 (테마별 선택 — §0 공통 시스템과 동일)

> **본문(`multipage_momopepe_body.txt`)과 반드시 같은 테마·hex를 쓴다.** 표지·본문이 다른 배경을 쓰면 시리즈가 깨진다.

| 테마 | 배경색 | 용도 |
|------|--------|------|
| **라이트 (기본)** | `#F8F8F8` (흰 카드 `#FFFFFF`) | 생활·소비·일반 주제 (필코노미 등) |
| **다크 (선택)** | `#1C1C1C` (카드 `#2A2A2A`) | 금융·투자 주제 (국민성장펀드 등) |
| **브랜드 블루** | `#1A3A6B` | 정책 공식 발표 |

> 실사 배경 사진은 라이트 테마의 *선택적 변형*일 뿐 기본이 아니다. 사용 시에도 본문과 동일 톤을 유지한다.

### 3-2. 포인트 컬러

| 역할 | 색상 | 헥스 코드 |
|------|------|-----------|
| 테두리 / 외곽선 | 진한 파란색 | `#1A3A8F` |
| **메인 타이틀** | **라임 그린 (본문과 동일)** | `#7FD62C` |
| 메인 타이틀 강조 단어 | 노란색 | `#FFD700` ~ `#FFC107` |
| 보조 타이틀 / 서브텍스트 | 흰색 | `#FFFFFF` |
| 말풍선 (흰색 배경형) | 흰색 바탕 + 검정 텍스트 | `#FFFFFF` / `#1A1A1A` |
| 말풍선 (강조형) | 검정 바탕 + 흰색 텍스트 | `#000000` / `#FFFFFF` |
| 서브타이틀 배너 | 크림/베이지 | `#F5E6C0` |
| 시리즈 로고 배경 | 연한 크림 | `#FFF8E7` |
| 재정경제부 MI 배경 | 흰색 또는 투명 | `#FFFFFF` |

### 3-3. 캐릭터 색상 참고 (모모 & 페페)

| 캐릭터 | 털 색상 | 특징 |
|--------|---------|------|
| **페페** (회색) | 회색 + 흰 배 | 흰 와이셔츠 + 파란 넥타이 착용 |
| **모모** (주황) | 주황/크림 | 베이지 계열 의상 착용 |

## 4. 타이포그래피

### 4-1. 폰트 체계

| 역할 | 폰트명 | 두께 | 크기 (1000px 기준) |
|------|--------|------|-------------------|
| **메인 타이틀** | 배달의민족 도현체 / 여기어때 잘난체 / Noto Sans KR Black | ExtraBold~Black | 90~130px |
| **서브타이틀** | Noto Sans KR / 본고딕 | SemiBold | 36~48px |
| **말풍선 텍스트** | 배달의민족 주아체 / 나눔손글씨 펜 | Regular~Bold | 30~42px |
| **시리즈 번호/태그** | Noto Sans KR | Bold | 24~30px |
| **MI 하단 기관명** | 공식 서체 (재정경제부 CI 준수) | Medium | 28~34px |

### 4-2. 텍스트 스타일 규칙

- **메인 타이틀**: 2줄 이내, 자간 -50 ~ -80 (꽉 찬 느낌), 가로 중앙 정렬
- 타이틀에 **물음표(?)** 또는 **이모지(🍞💰)** 포함 → 친근감 연출
- **외곽선(Stroke) 효과**: 타이틀 텍스트에 흰색 또는 검정 2~4px 외곽선 추가
- **말풍선**: 손글씨풍 폰트 사용, 불규칙한 각도(±5~10°) 허용
- **서브타이틀 배너**: 둥근 모서리(radius 8~12px) 크림색 박스 안에 텍스트 배치

## 5. 시각 요소 배치 가이드

### 5-1. 외곽 테두리

- 두께: **4~8px**
- 색상: 포인트 블루 (`#1A3A8F`)
- 포스터 전체를 감싸는 사각 테두리 (inner border)
- 모서리: **직각 (radius 0)** 또는 약간의 라운드(radius 8px)

### 5-2. 시리즈 로고 / 에피소드 표시 (상단 중앙)

```
[ 🔑 한입경제 #5 ]   ← 아이콘 + 시리즈명 + 에피소드 번호
```

- 작은 아이콘(열쇠, 동전 등) + 시리즈 이름 + 회차 번호
- 크림색 둥근 태그 형태
- 폰트 크기: 24~30px

### 5-3. 메인 타이틀 영역

- **1줄 또는 2줄** 구성
- 줄 1: 작은 설명 문구 (흰색, 30~40px) — 예: `나 우울해서 빵 샀어...`
- 줄 2: 핵심 키워드 (**라임 그린 `#7FD62C`**, 100~130px, Bold, 강조 단어만 노란색 `#FFD700`) — 예: `필코노미란?`
- 타이틀 아래: 크림색 배너 박스에 한 줄 부연 설명

### 5-4. 메인 캐릭터 이미지

- **3D 렌더링 고양이** 캐릭터 (모모/페페) 중앙 배치
- 캐릭터 높이: 전체 포스터의 **50~60%** 차지
- 위치: 세로 기준 **35~90%** 구간 (하단 MI 영역 위까지)
- 캐릭터는 **소품 착용** 권장: 음식, 서류, 동전, 가방 등 주제 연관 오브젝트
- 캐릭터 의상: **페페** = 흰 와이셔츠 + 파란 넥타이, **모모** = 베이지 자켓

### 5-5. 말풍선 (Speech Bubble)

- 캐릭터 좌측 상단 또는 우측 하단에 **2개** 배치
- 스타일 A: **흰 원형/타원형** 버블 + 검정 텍스트 (캐릭터 대사)
- 스타일 B: **검정 원형** 버블 + 흰 텍스트 (반응/질문)
- 폰트: 손글씨풍, ±5~8° 기울기

### 5-6. 재정경제부 MI (하단)

- 하단 중앙 배치, 포스터 하단에서 **3~5%** 여백
- 공식 로고 + `재정경제부` 텍스트
- 배경: 흰색 패드 또는 투명 (배경이 어두울 경우 흰색 로고 사용)
- 크기: 포스터 너비의 약 **25~30%**

## 7. 배경 처리 방식

### 실사 배경 사용 시 (라이트 테마)

- 주제와 연관된 실제 공간 사진 사용 (빵집, 카페, 사무실 등)
- 배경 밝기: **어둡게 처리(Overlay 50~70%)** 또는 블러 처리
- 캐릭터가 배경 위에 자연스럽게 합성된 느낌

### 단색/그라데이션 배경 (다크 테마)

- `#1A1A1A` 또는 `#000000` 단색
- 필요 시 상단에서 하단으로 미세한 그라데이션 (`#2A2A2A` → `#000000`)
- 별, 스파클 등 작은 장식 요소 추가 가능

## 9. 본문 페이지 (1~3페이지) 연계 레이아웃 힌트

> 표지 이후 본문 1~3페이지 제작 시 참고

- **헤더 영역**: 시리즈 로고(소형) + 페이지 번호 (우상단)
- **콘텐츠 영역**: 타이틀 + 설명 텍스트 + 인포그래픽/아이콘
- **캐릭터**: 본문에서는 캐릭터를 작게(포스터의 20~30%) 하단 또는 측면 배치
- **컬러 통일**: 표지와 동일한 포인트 컬러 유지
- **재정경제부 MI**: 본문 전 페이지 하단에 동일하게 배치
