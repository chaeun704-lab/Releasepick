# 재정경제부 카드뉴스 표지 디자인 템플릿

## 1. 기본 콘셉트

본 템플릿은 재정경제부 정책 홍보용 카드뉴스 표지를 제작하기 위한 디자인 가이드이다. 참고 이미지는 공통적으로 **밝은 배경, 큰 헤드라인, 3D 일러스트 캐릭터, 정책 키워드 배치, 정부 로고**를 활용하여 국민 친화적이고 신뢰감 있는 분위기를 형성한다.

핵심 방향은 다음과 같다.

- 어려운 정책 내용을 **쉽고 밝은 공공 캠페인 이미지**로 전달
- 중앙에는 **강한 메시지형 헤드카피** 배치
- 하단 또는 우측에는 **3D 캐릭터·사람·정책 상징 오브젝트** 배치
- 전체 톤은 **깨끗함, 친근함, 안정감, 미래지향성**을 유지
- 과도한 장식보다 **여백과 정보 위계**를 우선

- 정부로고(기관로고, 재정경제부 로고)는 C:\Users\USER\Releasepick\logo.png에 위치해있으니 해당 로고를 사용해.

- 용도: 인스타그램, 페이스북 카드뉴스, 홈페이지 썸네일
- 특징: 정책명·헤드라인·캐릭터를 균형 있게 배치하기 좋음

### B안: 세로형 표지 (앱 기본)

- 크기: `1000px × 1350px`
- 비율: 20:27
- 용도: 인스타그램 피드, 모바일 최적화 카드뉴스, **앱 생성 해상도**
- 특징: 상단 헤드라인, 하단 인물·오브젝트 구성에 적합

### C안: 포스터형 세로 카드 (인쇄·확대용 파생)

- 크기: **1000px × 1350px** 기준 비율(20:27) 유지하며 확대 (예: 2000×2700)
- 용도: 온라인 홍보 포스터, 메인 이미지
- 특징: 큰 메시지와 풍부한 일러스트를 동시에 표현 가능

참고 이미지의 인상은 세로형 비율에 가깝다. 따라서 기본 제작은 **1000×1350px**을 권장한다 (앱 생성 해상도와 동일).

## 4. 텍스트 구성 방식

### 4-1. 상단 정책명

- 위치: 상단 중앙 또는 좌상단
- 크기: 전체 높이의 약 3~5%
- 굵기: Bold 또는 SemiBold
- 색상: 네이비, 딥블루, 차콜
- 예시:
  - `2026 친환경 녹색 소비·관광`
  - `모두의 지역상권 추진 전략 2026`
  - `국민 생활비 부담 완화 프로젝트`

### 4-2. 메인 헤드라인

- 표지에서 가장 큰 요소
- 2~3줄 구성 권장
- 문장형보다 **구호형·호소형·결과 중심형**이 적합
- 크기: 전체 높이의 약 10~18%
- 굵기: ExtraBold 또는 Black
- 자간: 약간 좁게
- 행간: 0.95~1.1배

예시:

```text
에너지는 아끼고!
소비와 관광은 살리고!
```

```text
온기가 지방으로 퍼지는
모두의 지역상권
추진 전략 2026
```

```text
국민 생활에 힘이 되는
정책을 더 쉽게!
```

### 4-3. 키워드 배지

- 개수: 2~4개
- 형태: 둥근 사각형, 리본형, 화살표형, 알약형 버튼
- 위치: 헤드라인 아래
- 역할: 정책의 핵심 축을 빠르게 전달
- 텍스트 길이: 4~8자 권장

예시:

```text
[녹색 소비 확산] [친환경 관광 활성화] [민생안정 지원]
```

```text
[지역상권 회복] [AI 활용] [소상공인 지원]
```

### 4-4. 보조 설명 문구

- 위치: 키워드 배지 아래 또는 하단 일러스트 위
- 크기: 작게, 한 줄 또는 두 줄
- 색상: 회색, 차콜, 네이비
- 기능: 주최·취지·슬로건 보완

예시:

```text
민·관이 함께 만드는 지속 가능한 대한민국 프로젝트
```

## 7. 배경 디자인

### 7-1. 하늘색 배경형

- 배경: 밝은 하늘색 그라데이션
- 상단: 구름, 빛 번짐, 은은한 패턴
- 하단: 도시 실루엣, 건물, 산, 도로 등 얕은 명암의 배경
- 느낌: 여행, 소비, 미래, 친환경, 캠페인성 정책에 적합

디자인 요소:

- 흰 구름 2~3개
- 하단 도시 실루엣은 투명도 10~25%
- 원근감 있는 공간 구성
- 상단은 텍스트 가독성을 위해 최대한 단순하게 유지

### 7-2. 화이트 배경형

- 배경: 거의 흰색 또는 아주 연한 회색
- 도형: 원형, 물결선, 말풍선형 배경
- 정보 구조: 텍스트와 일러스트를 분리
- 느낌: 전략, 제도, 계획, 분석형 콘텐츠에 적합

디자인 요소:

- 민트색 원형 배경
- 퍼플색 반원 또는 장식 블록
- 검은색 손그림 느낌 곡선
- 작은 정책 상징 아이콘 배치

## 8. 이미지 및 일러스트 요소

### 8-1. 캐릭터 스타일

- 3D 클레이 또는 피규어 스타일
- 과장되지 않은 둥근 얼굴과 단순한 표정
- 밝고 친근한 의상
- 성별·연령·직업군을 다양하게 구성
- 정책 수혜자 또는 담당자처럼 보이게 연출

권장 캐릭터 예시:

- 청년
- 가족
- 소상공인
- 직장인
- 고령층
- 관광객
- 상인
- 공무원 또는 안내요원
- AI 로봇 캐릭터
- 공식 캐릭터 모모·페페

### 8-2. 오브젝트 스타일

- 3D 아이콘 또는 미니어처 형태
- 실제 사진보다 일러스트 중심 권장
- 필요 시 실제 사진은 카드 안의 작은 프레임 또는 배경 자료로 활용

정책별 오브젝트 예시:

| 정책 분야 | 추천 오브젝트 |
|---|---|
| 소비·관광 | 비행기, 캐리어, 카드, 지도 핀, 카메라, 선글라스 |
| 지역상권 | 상점, 시장, 건물, 간판, 골목길, 상권 지도 |
| AI·디지털 | 로봇, 노트북, 와이파이, 데이터 아이콘, 칩 |
| 민생안정 | 장바구니, 동전, 계산기, 영수증 |
| 청년정책 | 노트북, 책가방, 원룸, 취업 서류 |
| 친환경 | 나무, 잎사귀, 전기차, 태양광, 재활용 마크 |

### 8-3. 실제 사진 활용 시

- 표지 전체 배경으로 쓰기보다, 작은 카드·프레임 안에 삽입
- 사진 위에는 반투명 오버레이를 적용하여 톤 통일
- 인물 사진은 초상권·공식 사용 가능 여부 확인
- 정부 홍보물은 실제 사진보다 3D 일러스트가 더 부드러운 인상을 줌

## 10. 정부 로고 배치

- 위치: 하단 중앙 권장
- 크기: 전체 가로폭의 약 12~18%
- 주변 여백 충분히 확보
- 다른 장식 요소와 겹치지 않게 배치
- 흰 배경에서는 원본 로고 사용
- 컬러 배경에서는 흰색 박스 또는 반투명 배경을 활용 가능

## 11. 카드뉴스 표지 제작 절차

### Step 1. 정책 성격 분류

정책자료를 읽고 아래 중 하나로 분류한다.

- 캠페인형: 소비 촉진, 관광, 참여 독려, 이벤트
- 전략형: 추진전략, 종합대책, 기본계획
- 설명형: 제도 안내, 신청 방법, 변경 사항
- 성과형: 정책 성과, 통계 개선, 예산 집행 결과

### Step 2. 레이아웃 선택

- 캠페인형 → 하늘색 배경 + 중앙 정렬형
- 전략형 → 흰 배경 + 좌측 정렬형
- 설명형 → 카드형 정보 구조
- 성과형 → 숫자 강조 + 인포그래픽형

### Step 3. 핵심 문장 추출

정책자료에서 다음을 뽑는다.

- 정책명
- 국민에게 주는 변화
- 핵심 수치
- 핵심 대상
- 주요 혜택
- 참여 또는 신청 방법

### Step 4. 헤드카피 작성

좋은 헤드카피 조건:

- 15~28자 내외
- 2줄 구성 가능
- 동사 또는 효과 중심
- 국민 입장에서 이해 가능
- 어려운 행정용어 최소화

예시:

```text
생활비는 줄이고,
정책 혜택은 더 쉽게!
```

```text
지역의 온기를 살리는
상권 회복 프로젝트
```

### Step 5. 이미지 요소 선택

- 정책 대상자 2~5명
- 정책 상징 오브젝트 3~6개
- 배경 장식 2~4개
- 정부 로고 1개

### Step 6. 최종 검수

- 헤드라인이 한눈에 보이는가
- 정책 대상과 효과가 명확한가
- 글자가 너무 많은가
- 정부 로고가 안정적으로 보이는가
- 캐릭터와 오브젝트가 정책 내용과 연결되는가
- 색상 대비가 충분한가

## 14. 디자인 체크리스트

- [ ] 표지 첫 화면에서 정책명과 핵심 메시지가 3초 안에 보이는가
- [ ] 헤드라인이 2~3줄 이내인가
- [ ] 키워드 배지가 4개를 넘지 않는가
- [ ] 배경이 텍스트 가독성을 방해하지 않는가
- [ ] 캐릭터·오브젝트가 정책 내용과 연결되는가
- [ ] 전체 색상이 3~5개 이내로 통일되는가
- [ ] 정부 로고가 하단 중앙에 안정적으로 배치되는가
- [ ] 실제 사진 사용 시 출처·초상권 문제가 없는가
- [ ] 모바일 화면에서도 제목이 충분히 읽히는가
- [ ] 과장·선정적 표현 없이 공공기관 톤을 유지하는가

## 15. 제작 시 주의사항

- 카드뉴스 표지는 정보 전달보다 **첫인상과 클릭 유도**가 중요하다.
- 표지에는 세부 설명을 많이 넣지 않는다.
- 정책명은 작게, 국민에게 주는 변화는 크게 보여준다.
- 행정용어보다 생활 언어를 우선한다.
- 3D 일러스트는 귀엽지만 너무 유아적으로 보이지 않게 조절한다.
- 공공기관 홍보물인 만큼 과장된 감정 표현, 선정적 구도, 과도한 밈 표현은 피한다.
- 실제 정책자료 기반 제작 시 수치와 대상은 반드시 원문과 대조한다.

## 16. 최종 권장 디자인 방향

가장 안정적인 기본 조합은 다음과 같다.

```text
크기: 1000×1350px
배경: 하늘색 그라데이션 또는 화이트 배경
폰트: Pretendard ExtraBold + Medium
헤드라인: 상단 중앙 또는 좌상단 2~3줄
키워드: 둥근 배지 3개
이미지: 3D 클레이 스타일 인물 3~5명 + 정책 오브젝트
로고: 하단 중앙
톤: 밝고 친근하지만 공공기관다운 신뢰감 유지
```
