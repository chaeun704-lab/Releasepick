## 0. 표지와의 연결성 (가장 중요)

본문은 표지의 디자인 시스템을 상속하되, 표지 이미지를 반복하지 않는다. 
표지에 사용된 캐릭터의 자세, 장면 구도, 주요 오브젝트 조합은 본문에서 반복하지 않는다.
동일 카드뉴스 안에서 페이지가 바뀌어도 다음 4가지는 절대 변하지 않는다.

| 상속 항목 | 본문 적용 |
|---|---|
| **타이포그래피** | 표지와 같은 한글 서체(Pretendard / 에스코어드림 / 나눔스퀘어 Neo). 본문에서도 ExtraBold 메인 타이틀 + Medium 본문의 위계 유지 |
| **컬러 팔레트** | 표지에서 선택한 무드(A 웜 화이트 / B 스카이 블루 / 그린 등)의 베이스·텍스트·액센트를 그대로. 본문에서 1~2개 액센트를 더 자주 노출 |
| **3D 일러스트 룩** | 표지와 동일 캐릭터 디자인·매트 표면·파스텔 톤. 사진/플랫 아이콘과 혼용 금지 |
| **하단 시그니처** | 표지와 동일한 위치·크기·색의 발행 기관 엠블럼 |

추가로, **시리즈 식별자(상단 알약 칩)** 가 표지와 본문을 시각적으로 묶는다. 표지에 직접 등장하지 않더라도, 본문 1~3페이지의 상단 칩 문구는 표지 타이틀에서 파생된 짧은 키 카피여야 한다.

```
표지:        2026 모두의 지역상권 추진 전략
            ↓
본문 상단 칩: ▮ 2026 모두의 지역상권 추진전략 ▮  點:창업 | …
```

## 1. 캔버스 / 비율

| 항목 | 값 |
|---|---|
| 종횡비 | **20 : 27 (세로형, 1000:1350)** — 표지와 동일 |
| 해상도 | **1000 × 1350 px** (권장·앱 생성 동일) |
| 안전 여백 | 좌우 50 px, 상하 50 px |
| 배경 | 표지 베이스 컬러보다 **5~8% 더 밝거나 화이트에 가깝게**. 본문은 정보 가독성 우선 |

본문 페이지는 표지보다 **여백을 좁히고 본문 영역을 넓힌다.** 같은 20:27 비율 안에서 정보 밀도를 높이기 위함.

## 2. 본문 페이지 구조 (정보형 / 1·2페이지 공통)

```
┌─────────────────────────────────────┐
│ ① 시리즈 칩 + 사이드 카피 (소)        │  ← 상단 8%
├─────────────────────────────────────┤
│ ② 메인 타이틀 (1~2줄, 핵심 키워드 강조)│  ← 12~16%
├─────────────────────────────────────┤
│ ③ 콘텐츠 카드 #1                     │  ← 38~44%
│    [컬러 칩 헤더] + 본문 불릿 + 일러스트│
├─────────────────────────────────────┤
│ ④ 콘텐츠 카드 #2                     │  ← 28~34%
│    [컬러 칩 헤더] + 본문 불릿 + 일러스트│
├─────────────────────────────────────┤
│ ⑤ 발행 기관 시그니처 (선택, 작게)      │  ← 4%
└─────────────────────────────────────┘
```

- **카드는 페이지당 1~2개**. 3개를 넘으면 글자가 작아져 모바일에서 가독성 붕괴
- 카드끼리 **컬러는 다르게**(예: 1번 카드 라벤더, 2번 카드 그린) — 시각 리듬 부여
- 일러스트는 카드 안에서 **우측 또는 좌측 정렬**, 카드 간 좌우 위치를 교차해 흐름을 만든다

## 3. 본문 페이지 구조 (이미지+카피 격자 / 항목 나열형)

참고 이미지 4(`친환경 녹색 소비 촉진`)처럼 **소형 일러스트 + 짧은 카피** 가 4~5개 나열되는 변형 레이아웃.

```
┌─────────────────────────────────────┐
│ 상단 칩 + 기관 로고 (우측)            │
│ 메인 타이틀 (키워드 밑줄/배경 강조)    │
├──────────┬──────────────────────────┤
│ [일러]   │ 카피 1                   │
├──────────┼──────────────────────────┤
│ 카피 2   │ [일러]                   │  ← 좌우 교차
├──────────┼──────────────────────────┤
│ [일러]   │ 카피 3                   │
├──────────┴──────────────────────────┤
│ 카피 4 + [일러]                      │
└─────────────────────────────────────┘
```

각 항목 사이는 **얇은 점선 또는 여백** 으로만 구분(박스 X). 정보가 카드처럼 갇혀 보이지 않게.

## 4. 마무리 페이지 구조 (3페이지 / 클로징)

참고 이미지 3, 5처럼 **메시지를 단단히 마무리하는** 단일 구성.

```
┌─────────────────────────────────────┐
│                                     │
│   [상단 ~10% 여백]                   │
│                                     │
│   ┌────────────────┐                │
│   │  3D 캐릭터 컷   │  ← 페이지 폭의 │
│   │  (또는 그룹샷)  │     40~55%    │
│   └────────────────┘                │
│                                     │
│   정부는 / 정부와 민·관은            │
│   [핵심 정책 키워드] 을(를)          │  ← 중앙 정렬
│   [동사: 추진해 / 만들어 가겠습니다]  │     본문 3~5줄
│                                     │
│                                     │
│        [기관 엠블럼 + 명]            │  ← 하단 중앙
└─────────────────────────────────────┘
```

특징:
- 배경은 **거의 순백**(`#FFFFFF` ~ `#FBFAF7`) — 정보형 페이지보다 한 톤 밝게
- 일러스트와 본문 사이 간격을 **시원하게** 띄움(80~120 px)
- 본문은 **중앙 정렬**, 3~5줄, 행간 1.8
- "정부는 ~ 해 나가겠습니다" 식의 **선언적·약속 톤** 카피

## 5. 타이포그래피

### 텍스트 위계 (1000 × 1350 기준)

| 역할 | 크기 | 굵기 | 컬러 | 비고 |
|---|---|---|---|---|
| 시리즈 칩 텍스트 | 22–26 px | Bold | #1A2238 / 칩에 따라 흰색 | 칩 배경: 옅은 그레이 `#E5E2DA` 또는 페이지 무드색 |
| 사이드 카피(`點:창업 | …`) | 20–24 px | Medium | #4A5060 | 칩 우측에 인라인 배치 |
| **본문 메인 타이틀** | **52–68 px** | **ExtraBold (800)** | **#1A2238** | 표지 타이틀보다 **30~40% 작게** |
| 키워드 강조 | 메인 타이틀 크기 | ExtraBold | 동일 + **하단 배경 컬러 강조** | 예: `로컬창업`, `골목상권` |
| 카드 헤더 칩 | 28–34 px | Bold | 흰색 | 컬러 배경 알약 |
| 본문 불릿(■) | 26–30 px | Regular/Medium | #1A2238 | 행간 1.55 |
| 본문 강조 키워드 | 동일 | Bold | 동일 또는 액센트색 | 단어 단위로만 |
| 보조 설명 `(26.~, 1억원)` | 22–26 px | Regular | #6A6F7E | 괄호 안 메타 정보 |
| 마무리 본문 | 30–36 px | Regular (Bold 부분 혼용) | #2C3142 | 중앙 정렬, 행간 1.75 |

### 키워드 강조 표현 (3가지 중 택1, **페이지 내 1종으로 통일**)

1. **하단 컬러 블록**: 글자 뒤에 50% 높이의 액센트 배경 (참고 이미지 4의 `친환경 녹색 소비 촉진`)
2. **단순 굵기 + 액센트 컬러**: `**모두의 '로컬창업'**` 식으로 따옴표·굵기로만 강조
3. **밑줄 액센트**: 글자 아래 4~6 px 두께의 액센트 컬러 라인

⚠️ 표지 타이틀에서 사용한 강조 방식과 **다르지 않아야** 한다.

## 7. 일러스트레이션 가이드 (본문)

표지와 같은 **3D 매트 렌더 룩**을 유지하되, 본문에서는 역할이 두 가지로 나뉜다.

### A. 스폿 일러스트 (본문 카드 내)
- 카드 안 텍스트 옆에 배치, 크기는 카드 높이의 **60~80%**
- 캐릭터 + 1~2개 보조 오브젝트로 구성
- 배경 없이 잘려 나온 모양(누끼). 그림자만 살짝
- 카드 헤더 컬러와 **의류·소품 컬러가 충돌하지 않게** 보색 회피

### B. 디테일 일러스트 (이미지+카피 격자 페이지)
- 단일 오브젝트 또는 소품 클로즈업 (예: 충전기, 전기차, 카드, 자전거)
- **120 × 120 ~ 240 × 240 px** 사이
- 일러스트 옆에 한 줄 굵은 카피(타이틀) + 한 줄 본문 카피

### C. 마무리 일러스트
- 시리즈의 메시지를 응축하는 **상징적 컷**
- 캐릭터 그룹 + 슬로건 보드(이미지 3) 또는 캐릭터 듀오(이미지 5) 식
- 캔버스 폭의 40~55% 차지, 중앙 배치

### 화살표 표현 (정보 흐름)

본문 불릿에서 자주 사용:
```
■ 메인 항목 (큰 사각형, 굵게)
➡ 하위 보조 항목 (작은 화살표, 다음 줄로 인덴트)
```
- `■` 컬러: 텍스트와 동일(`#1A2238`)
- `➡` 컬러: 카드 헤더 칩과 동일한 액센트
- 둘 사이 들여쓰기 24~32 px

## 8. 보조 그래픽 요소

### 시리즈 칩 (상단 좌측)
- 라운드 12 px, 좌우 패딩 20 px, 높이 44~50 px
- 텍스트 옆 작은 도트(•) 또는 `|` 로 보조 카피 분리
- 우측에 발행 기관 로고를 인라인으로 배치하기도 함(참고 이미지 4)

### 카드 컨테이너
- 라운드 **24~32 px**, 그림자 `0 4 16 rgba(0,0,0,0.04)`
- 내부 패딩 32~40 px
- 카드 헤더 알약은 카드 좌상단 안쪽 또는 카드 상단을 **반쯤 걸쳐서** 배치(참고 이미지 1, 2)

### 강조 배지 (`×2`, `최대 5%P`, `우대` 등)
- 작은 라운드 사각형 또는 리본 모양
- 옐로우(`#F0C24B`)·코랄·민트 등 **카드 헤더와 다른 액센트** 사용 → 시선 끌기
- 텍스트는 굵게, 화이트 또는 다크네이비

### 점선 흐름 연결
- 카드 #1 일러스트 → 카드 #2 일러스트로 곡선 점선 연결(옵션)
- 두께 2 px, dash 8 8, 컬러 `#C9C2B6`

## 9. 페이지 시퀀스 가이드 (1~3페이지)

### 시퀀스 A — 정책 발표형 (지역상권 시리즈 패턴)
```
표지   → 본문 1: 핵심 전략 #1 (카드 2개)
       → 본문 2: 핵심 전략 #2 (카드 2개)
       → 본문 3: 마무리 메시지 (선언형)
```
- 본문 1·2는 **컬러 무드는 같고 액센트만 다르게** (라벤더→그린→오렌지 식 점진 변주)
- 카드 헤더 칩의 컬러가 페이지를 넘어가며 자연스럽게 전환되면 시리즈성↑

### 시퀀스 B — 항목 나열형 (BOOM-UP 시리즈 패턴)
```
표지   → 본문 1: 카테고리 A (그리드 4~5칸)
       → 본문 2: 카테고리 B (그리드 4~5칸)
       → 본문 3: 마무리 메시지 (선언형)
```
- 카테고리마다 **단일 액센트 컬러**로 통일(녹색 소비=그린, 친환경 관광=블루 등)
- 본문 페이지의 메인 타이틀에서 키워드 강조 배경색이 그 카테고리 컬러

### 공통 규칙
- 3페이지는 **항상 마무리 페이지** (정보 추가 금지, 메시지 마침표)
- 1·2페이지에서 사용한 캐릭터가 3페이지에 다시 등장하면 시각적 통일성 ↑

- [ ] 페이지당 카드 2개 이하, 카드별 액센트 컬러 명확
- [ ] 메인 타이틀 키워드 강조 방식이 페이지 간 동일
- [ ] 불릿 위계(■ → ➡)가 일관되게 적용
- [ ] 메타 정보(`(26.~, 1억원)`)가 본문 색보다 흐린 그레이로 분리
- [ ] 보조 배지(`×2`, `최대 5%P`)는 본문 카드와 다른 액센트
- [ ] 마무리 페이지에 정보를 추가로 욱여넣지 않았는지
- [ ] 마무리 페이지 일러스트가 표지와 같은 캐릭터 시스템인지
- [ ] 하단 기관 시그니처 위치·크기·컬러가 표지와 동일
- [ ] 모바일 썸네일(1000×1350의 1/4 크기)에서 본문 가독성 확인
