## 0. 멀티페이지 카드뉴스의 원칙 (가장 중요)

2~5장 카드뉴스는 **표지 → 본문(정보 전개) → 마무리(선언·약속)** 의 3단 역할로 구성한다. 페이지 수가 늘어날수록 본문 정보 밀도만 조절하고, 아래 4가지는 **전 페이지에서 절대 변하지 않는다.**

| 상속 항목 | 멀티페이지 적용 |
|---|---|
| **타이포그래피** | 표지와 동일 서체(Pretendard / 에스코어드림 / 나눔스퀘어 Neo). ExtraBold 메인 타이틀 + Medium 본문 위계 유지 |
| **컬러 팔레트** | 선택한 컨셉(①경제·②복지·③미래)의 베이스·텍스트·액센트를 표지→본문→마무리까지 일관 |
| **3D 일러스트 룩** | 표지와 동일 캐릭터·매트 표면·파스텔 톤. 플랫 아이콘·실사 혼용 금지 |
| **하단 시그니처** | 표지와 동일 위치·크기·색의 발행 기관 엠블럼 |

### 페이지 역할 분담

| 페이지 | 역할 | 정보 밀도 |
|---|---|---|
| **표지 (1장)** | 정책명·핵심 메시지·시각적 후킹 | 낮음 — 헤드라인 + 3D 일러스트 중심 |
| **본문 (2~N-1장)** | 정책 내용·수치·절차·혜택 전개 | 높음 — 카드·불릿·인포그래픽 |
| **마무리 (마지막 장)** | 정부 약속·비전·선언형 메시지 | 낮음 — 정보 추가 금지, 메시지 마침표 |

```
2장: 표지 → 마무리
3장: 표지 → 본문 1 → 마무리
4장: 표지 → 본문 1 → 본문 2 → 마무리
5장: 표지 → 본문 1 → 본문 2 → 본문 3 → 마무리
```

> **마지막 장은 항상 마무리 페이지.** 본문 가이드 §4(클로징) 구조를 따른다.

## 2. AI 자동 분류 규칙

업로드된 보도자료 키워드를 분석하여 아래 3컨셉 중 하나를 **기본 추천값**으로 제시한다. 사용자는 썸네일 미리보기와 함께 최종 선택한다.

### ① 종합경제정책 및 성장 (`mp_economy`)

**추천 키워드:** 경제정책, 경제성장, 성장전략, 산업정책, 수출, 투자, 기업지원, 경제활력, 혁신성장, 국가경쟁력

**예시 보도자료:** 경제정책방향, 하반기 경제정책방향, 기업투자 활성화 대책, 수출지원 정책, 혁신성장 전략

### ② 세금 및 복지혜택 (`mp_welfare`)

**추천 키워드:** 세금, 세제, 감면, 공제, 환급, 복지, 지원금, 장려금, 바우처, 청년지원, 서민지원

**예시 보도자료:** 근로장려금, 자녀장려금, 세액공제, 세제혜택, 민생지원정책, 소상공인 지원

### ③ 미래경제 및 친환경 (`mp_future`)

**추천 키워드:** 미래산업, AI, 디지털, 탄소중립, ESG, 녹색성장, 친환경, 신재생에너지, 미래기술, 혁신기술

**예시 보도자료:** 탄소중립 정책, AI 산업육성, 디지털 전환, 그린뉴딜, 미래산업 육성전략

## 3. 표지 페이지 구조 (3컨셉 공통)

[`템플릿(표지).txt`](./템플릿1/템플릿(표지).txt) §2~§5를 기본으로 하되, 컨셉별 액센트·일러스트 주제만 바꾼다.

```
┌─────────────────────────────────────┐
│ ① 상단 정책명 / 프로젝트명 (소)       │  ← 6~8%
├─────────────────────────────────────┤
│ ② 메인 헤드라인 (2~3줄, ExtraBold)   │  ← 20~28%
├─────────────────────────────────────┤
│ ③ 핵심 키워드 배지 2~4개             │  ← 8~10%
├─────────────────────────────────────┤
│ ④ 3D 캐릭터 + 정책 상징 오브젝트     │  ← 35~42%
├─────────────────────────────────────┤
│ ⑤ 보조 설명 (1줄, 선택)              │  ← 6~8%
├─────────────────────────────────────┤
│ ⑥ 발행 기관 엠블럼 (하단 중앙)        │  ← 4~6%
└─────────────────────────────────────┘
```

- 표지 일러스트는 **컨셉 상징**(성장 그래프 / 혜택 아이콘 / 스마트시티 등)을 3D 매트 스타일로 표현
- 본문에서 **동일 자세·구도·오브젝트 조합을 반복하지 않는다** (본문 가이드 §0)

## 4. 본문 페이지 구조 (2~N-1장 공통)

[`템플릿(본문).txt`](./템플릿1/템플릿(본문).txt) §2~§3을 따른다. 컨셉에 따라 **정보형(카드 2개)** 또는 **격자형(항목 4~5칸)** 중 택1.

### A. 정보형 (정책 발표·성장·산업 정책에 적합)

```
┌─────────────────────────────────────┐
│ ① 시리즈 칩 + 사이드 카피            │  ← 상단 8%
├─────────────────────────────────────┤
│ ② 메인 타이틀 (키워드 강조)          │  ← 12~16%
├─────────────────────────────────────┤
│ ③ 콘텐츠 카드 #1                     │  ← 38~44%
│    [컬러 칩 헤더] + 불릿 + 3D 스폿    │
├─────────────────────────────────────┤
│ ④ 콘텐츠 카드 #2                     │  ← 28~34%
│    [컬러 칩 헤더] + 불릿 + 3D 스폿    │
├─────────────────────────────────────┤
│ ⑤ 발행 기관 시그니처 (선택)          │  ← 4%
└─────────────────────────────────────┘
```

- 페이지당 카드 **1~2개**. 3개 초과 금지
- 카드별 액센트 컬러를 다르게(라벤더→민트→피치 등) — 페이지 간 시각 리듬

### B. 격자형 (세제·복지·항목 나열 정책에 적합)

```
┌─────────────────────────────────────┐
│ 상단 칩 + 기관 로고 (우측)            │
│ 메인 타이틀 (키워드 밑줄/배경 강조)    │
├──────────┬──────────────────────────┤
│ [3D일러] │ 카피 1 (타이틀+1줄 설명)   │
├──────────┼──────────────────────────┤
│ 카피 2   │ [3D일러]  ← 좌우 교차     │
├──────────┼──────────────────────────┤
│ [3D일러] │ 카피 3                   │
├──────────┴──────────────────────────┤
│ 카피 4 + [3D일러]                    │
└─────────────────────────────────────┘
```

- 항목 사이는 **얇은 점선 또는 여백**만 (박스 테두리 X)
- 소형 3D 오브젝트: 120×120 ~ 240×240 px

## 5. 마무리 페이지 구조 (마지막 장 공통)

본문 가이드 §4와 동일. **정보 추가 금지**, 선언형 카피만.

```
┌─────────────────────────────────────┐
│   [상단 ~10% 여백]                   │
│   ┌────────────────┐                │
│   │  3D 캐릭터 컷   │  ← 폭 40~55%  │
│   └────────────────┘                │
│   정부는 / 정부와 민·관은            │
│   [핵심 정책 키워드] 을(를)          │  ← 중앙 정렬 3~5줄
│   [동사: 추진해 / 만들어 가겠습니다]  │
│        [기관 엠블럼 + 명]            │  ← 하단 중앙
└─────────────────────────────────────┘
```

- 배경: `#FFFFFF` ~ `#FBFAF7` (본문보다 한 톤 밝게)
- 톤: "정부는 ~ 해 나가겠습니다" 식 **선언·약속**

Clean government economic policy card preview. Upward growth charts, innovation light bulb, connected gears, corporate blue and pastel green, 3D matte illustration style, trustworthy public communication, bright white-blue background, no readable text, no logos.

