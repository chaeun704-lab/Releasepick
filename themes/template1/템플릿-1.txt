# 카드뉴스 1장(단일 페이지) — template2 통합형 (풍부·다양)

> **동일 디자인 시스템:** `themes/template2/템플릿1/템플릿(표지).txt` + `템플릿(본문).txt`
> 본문 문안은 **단일 블록**, 시각 디자인은 **풍부·다양**하게.

---

## 0. 본문 구성 (유지)

- 헤드라인 아래 **3칸 요약·배지 줄·1·2 번호 분할** 금지
- 모든 불릿 → **단일 본문 카드 1개**에 연속 배치

---

## 1. 시각 다양화 (풍부하게)

| 요소 | 적용 |
|---|---|
| **배경** | 섹션 톤 그라데이션, 구름·실루엣·원형 장식 |
| **헤드라인** | 단일 색 ExtraBold — 형광펜·컬러박스·밑줄 **금지** |
| **단일 본문 카드** | 컬러 헤더 칩, 좌측 액센트 띠, 그림자, **불릿 내 키워드 Bold+액센트색** |
| **3D** | 클레이 캐릭터+오브젝트 25~40%, 눈에 띄게 |
| **시안 A/B/C** | 후보마다 배경·구도·3D 배치 다르게 |

---

## 2. 시안별 차별 (A/B/C)

### 시안 A · 하늘색 중앙형
- 스카이블루 그라데이션 + 구름, 가운데 정렬, 중하단 대형 3D

### 시안 B · 웜톤 좌우 분할
- 웜 오프화이트 + 민트·퍼플 원형 장식, 좌 텍스트·우 3D

### 시안 C · 대각 밴드·하단 비주얼
- 대각 컬러 밴드 + 도시 실루엣, 하단 3D 오브젝트 밴드

---

## 3. 페이지 구조

```
시리즈 칩 → 헤드라인(단색 ExtraBold) → [단일 꾸민 본문 카드] → 3D 일러스트 → 마무리
```
